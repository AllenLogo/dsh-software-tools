# 新增软件工具到【软件工具】目录

## 目标

用户装了一个新软件,希望它出现在 dsh 侧边栏 **🔧 软件工具** 面板里,勾选后注入模型上下文(系统提示段落),让模型知道这个软件存在且知道怎么调用。

## 机制(重要)

- 【软件工具】插件的工具目录 = **内置目录 + 用户扩展目录合并**。
- **用户扩展目录文件**:`$DSH_HOME/software-tools/catalog.json`(JSON,形如 `{"tools": [条目...]}`;`$DSH_HOME` 默认 `~/.dsh`,插件 config 可用 `settingsDir` 覆盖)。
- 写这个文件**无需重编译、无需重启、无需重装插件**——宿主每次读取都实时合并,刷新面板即可见。
- **不要修改**插件的内置目录(在 `~/.dsh/profiles/web/node_modules/dsh-software-tools/` 里,升级会被覆盖)。

## 步骤

### 1. 调研该软件(用只读命令)

搞清楚三件事:

1. **它是什么 / 干什么用**(一句话,面向"模型要决定何时用它")
2. **怎么从本机调用**:
   - 如果跑在 WSL(命令行工具):给出真实可用的 bash 命令
   - 如果跑在 Windows(桌面/服务/下载器):给出经 WSL interop 的调用法(`cmd.exe /c "..."` 或直接调 Windows exe),以及监听端口/配置路径(如有)
3. **必要的环境事实**:端口、代理、默认目录、依赖前提(如"需先启动"、"需 API key 存在某环境变量")

可用 `which`、`ls /mnt/c/...`、`curl 探活` 等确认;不确定的写"需确认",不要编造路径。

### 2. 构造目录条目

```json
{
  "id": "软件A的唯一id",
  "name": "软件 A 的显示名",
  "category": "download | proxy | media | browser | knowledge | runtime | model | misc",
  "desc": "一句话说明它是做什么的",
  "usage": "1-2 行可执行的调用法,模型会逐字读到"
}
```

约束(校验规则,违反会出问题):

| 字段 | 规则 |
|---|---|
| `id` | `[a-z0-9-]{1,32}`,全局唯一;与已有 id 相同 = **覆盖内置条目**(可用于修正内置用法) |
| `category` | 必须在上述枚举内(新软件不确定就选 `misc`) |
| `desc` | 一句话,≤ 40 字,说明"何时用" |
| `usage` | **自包含、可直接执行**:真实命令、完整路径、端口;Windows 工具写清 interop 调用法,如 `cmd.exe /c "C:\\...\\工具.exe" /参数`;依赖前提写明(如"需先启动"、"目标目录需先建好") |

### 3. 写入文件

```bash
STDIR="${DSH_HOME:-$HOME/.dsh}/software-tools"
mkdir -p "$STDIR"
# 若 catalog.json 不存在,创建 {"tools": []};存在则读出来合并
```

用 read 读现有文件(不存在则视为空),按 `id` 合并(同 id 覆盖),写回 `{"tools": [...]}`。写完后**用 python3/json 校验 JSON 合法**。

### 4. 验证与告知

- 校验 JSON 合法、字段齐全、id 唯一
- 告知用户:**刷新页面 → 打开 🔧 软件工具 → 新软件出现在对应分类**(可勾选注入;或让我用 `curl` 调 `/_dsh-software-tools/list` 验证它已进入目录)
- 如果用户希望模型**立即可用**(不等勾选),提醒:勾选后才注入上下文

## 示例

用户说"我把 ffmpeg 装好了,加进软件工具":

```json
{
  "id": "ffmpeg",
  "name": "ffmpeg (音视频处理)",
  "category": "media",
  "desc": "命令行音视频转码/剪辑/合成工具,已安装。",
  "usage": "ffmpeg -i 输入.mp4 -c:v libx264 -preset fast 输出.mp4 ;查看编码器 ffmpeg -encoders。"
}
```

## 注意

- 一次只加一个软件;批量时逐个按此流程
- 不要改内置目录文件、不要改插件源码
- usage 里的命令必须是这台机器(或 Windows 侧)真实可用的,别写假设性命令
